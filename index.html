01 / ASR

本地语音识别

FunASR Paraformer 中文识别，跑在本地 RTX 5070 的独立虚拟环境里，全程不经过云端 ASR。

02 / LLM

云端大模型

统一客户端封装，角色卡与历史上下文注入；密钥不进固件、不进日志。

03 / TTS

本地语音合成

CosyVoice 3.0 为主、GPT-SoVITS 备选；HTTP 仅监听回环地址，绝不静默回退云端。

04 / PROTOCOL

半双工通信

WebSocket 双向 17 种消息类型，按 session / turn 严格区分轮次，支持打断与重连。

05 / CARD

角色卡系统

YAML / JSON 描述 30+ 字段：性格、语气、口癖、音色、禁止行为，改卡即改人设。

06 / SAFETY

隐私与安全

音频不落盘、不留存；本地服务不暴露公网；异常时明确降级而非静默失败。

04
开发路线

七个阶段，把闭环走通

严格分阶段推进：每个阶段先验收再进入下一阶段，绝不一次性生成大量未验证代码。这是项目能真正跑起来的前提。

PHASE 01

本地 ASR 验证

环境检查 → 独立虚拟环境 → FunASR Paraformer 跑通中文识别，建立性能基线。

ASR
PHASE 02

云端 LLM 接入

统一 LLM 客户端封装，验证角色卡遵循度、首 token 延迟与限流处理。

LLM
PHASE 03

本地 TTS + 对话服务

评估 CosyVoice 3.0，搭建本地 TTS HTTP 接口，接通 ASR + LLM + TTS 最简闭环。

TTS
PHASE 04

WebSocket 通信

定义统一消息协议，完成客户端模拟器，测试上传、下发、打断与断线重连。

PROTOCOL
PHASE 05

ESP32-S3 固件

Wi-Fi 连接、麦克风采集、按键交互、音频播放、WebSocket 与 LCD 状态显示。

FIRMWARE
PHASE 06

整机联调

从录音到播放完整跑通，测多轮对话、网络中断与服务异常，记录全链路延迟。

INTEGRATION
PHASE 07

稳定性与性能优化

依真实数据调参，评估流式 ASR / LLM / TTS，检查显存占用与长时间稳定性。

TUNING
